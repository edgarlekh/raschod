## 2026-09-14 — Дизайн-система: токены (референсы revolut/wise, не копия)

Прочитал `revolut/DESIGN.md` и `wise/DESIGN.md` (awesome-design-md) —
оба про маркетинговые сайты (hero-band, footer, plan-card), не про
мобильный продуктовый UI, поэтому беру не компоненты, а принципы:
- Revolut: высокий контраст тёмного/светлого канваса, pill-кнопки,
  жёсткая типографика без лишних декораций, скупой acccent-цвет.
- Wise: один яркий brand-accent (не палитра из десяти), крупный
  radius на карточках (не sharp corners), дружелюбный, не банковский.

Raschod — не финтех-бренд с наследием, поэтому не копирую ни один
токенсет один-в-один. Решение (для Plan 2, "Design System Foundation"):
- **Accent**: один яркий акцент (обсуждается в Plan 2 — кандидат:
  тёплый лайм/мятный на тёмном канвасе, ассоциация "рост/накопление",
  не банковский синий-по-умолчанию).
- **Radius**: крупный (16–24px) на карточках/модалках трения — мягче,
  менее "банковский", подходит для "дружелюбного давления", не
  наказания.
- **Тёмная тема — основная** (Revolut-подход), светлая — зеркальная
  пара, обе через системную настройку (решено ранее).
- Типографика: системный шрифт (SF Pro/Roboto через RN default) —
  не тащим платный/проприетарный шрифт (Aeonik Pro / Wise Sans) ради
  чистоты лицензии и веса бандла; жирный display-вес (700-800) для
  крупных чисел (баланс, прогресс цели) — единственное "громкое" место.
- Кнопки: pill-shaped (rounded.full) — из Revolut.
- Elevation: без теней, через цветовые слои (canvas → surface →
  elevated) — из обоих референсов, современнее чем classic drop-shadow.

Точные hex/px значения — в Plan 2 spec addendum, не здесь (DECISIONS.md
для обоснований, не для токенов).

## 2026-09-14 — Quick Capture UX: "думаю потратить" ≠ "уже потратил"

Пользователь указал на важный момент: решение о покупке (пока деньги не
ушли) и запись уже случившейся траты — разные события, и трение имеет
смысл только для первого. Схема БД это уже поддерживает (frictionLevel/
wasSkipped из Plan 1) — новой миграции не нужно, это чисто UX-решение.
Полный дизайн флоу — `docs/superpowers/specs/2026-09-14-quick-capture-ux-addendum.md`.

Ключевое: глобальная плавающая кнопка быстрого входа (сразу клавиатура,
категория после), тумблер "Сейчас" (включает трение) / "Уже потратил"
(трение выключено полностью, всегда), трение — свайп-карточки (не
модалка с текстом), последняя карточка на heavy-тире = сама
opportunity-cost визуализация с решением свайпом на ней же. Асимметрия
реакции: пропуск траты получает более праздничную анимацию, чем покупка
— усиливаем именно контроль, а не трату.

Влияет на следующий план (App Shell): плавающая кнопка — часть шелла с
первого дня, не долепляется потом.
